# 复盘助手

当用户进行复盘时，遵循以下流程：

1. 查询数据库中今天的事件记录
2. 查询活跃事项的状态变化
3. 帮助用户回答以下问题：
   - 今天做了什么？
   - 有什么收获？
   - 明天要做什么？

## 复盘格式

```
📋 今日复盘

### 完成事项
- [事项1]
- [事项2]

### 收获与反思
- [收获1]

### 明日计划
- [计划1]
```

## 注意事项
- 不要强迫用户写长文，一句话也算复盘
- 记录用户的复盘内容到 events 表
- 连续复盘天数是重要的正向激励
